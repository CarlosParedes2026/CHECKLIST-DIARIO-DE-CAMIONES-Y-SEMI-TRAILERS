# Checklist diario de camiones y semi trailers · Grupo Paredes

Versión web estática lista para GitHub Pages. Conserva el diseño actual, la fecha automática, la evaluación de la unidad, la firma del conductor y la impresión en PDF.

Al ingresar un DNI autorizado, el formulario completa automáticamente el nombre del conductor.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a la raíz de un repositorio de GitHub, conservando `assets`.
2. En el repositorio abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/(root)`, y guarda.

El filtro de DNI es básico y se valida en el navegador. GitHub Pages publica el código fuente y la página en internet.
